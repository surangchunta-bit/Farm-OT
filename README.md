# Money Farm — HRM OT Calculator

แอปคำนวณ OT และบริหารเงินส่วนตัว ธีมเกมฟาร์ม

ทั้งแอปอยู่ใน `index.html` ไฟล์เดียว — ฟอนต์ ไอคอน และสูตรคำนวณฝังอยู่ในนั้นหมด
ไม่มี dependency ไม่ต้อง build ไม่มี backend

## ใช้งาน

- เปิดไฟล์ตรง ๆ ในเบราว์เซอร์ก็ใช้ได้เลย
- หรือเอาขึ้นเว็บ: อัปไฟล์นี้ขึ้น GitHub แล้วเปิด GitHub Pages / import เข้า Vercel

`vercel.json` บอก Vercel ว่าไม่ต้อง build ไม่ต้อง install เสิร์ฟไฟล์ตรง ๆ อย่างเดียว

## สำคัญ

repo นี้ต้อง **ไม่มี** `package.json` และ `next.config.mjs`
ถ้ามี Vercel จะเข้าใจว่าเป็นโปรเจกต์ Next.js แล้วพยายาม build จนพัง

## ข้อมูล

เก็บใน localStorage ของเครื่องที่เปิด ไม่มีการส่งออกไปไหน ล้างได้ที่หน้าตั้งค่าในแอป
