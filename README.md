# Money Farm — HRM OT Calculator

ถ่ายรูปใบ OT → AI อ่านตัวเลขให้ → สรุปว่าเดือนนี้เหลือใช้เท่าไหร่

```
.
├── index.html      ← ทั้งแอปอยู่ในไฟล์นี้ (UI + สูตร + ฟอนต์ + ไอคอน)
├── api/ocr.js      ← ตัวอ่านเอกสาร ทำงานบนเซิร์ฟเวอร์ Vercel
├── vercel.json
└── README.md
```

---

## ⚠️ ต้องทำ 2 ขั้นก่อนตัวอ่านจะทำงาน

ถ้าไม่ทำ แอปยังใช้ได้ปกติ แต่จะให้กรอกตัวเลขเองแทนการอ่านอัตโนมัติ

### 1. ขอ API key

ไปที่ https://console.anthropic.com → **API Keys** → **Create Key** → คัดลอกไว้
ต้องเติมเครดิตก่อนถึงจะเรียกใช้ได้ ดูราคาปัจจุบันที่ https://claude.com/pricing

### 2. ใส่ key ลง Vercel

Vercel → เข้าโปรเจกต์ → **Settings** → **Environment Variables**

| ช่อง | ใส่ |
|---|---|
| Key | `ANTHROPIC_API_KEY` |
| Value | key ที่คัดลอกมา |
| Environments | ติ๊กให้ครบทั้ง Production, Preview, Development |

**Save** แล้วไปที่ **Deployments** → **Redeploy**
(ต้อง redeploy ทุกครั้งที่แก้ค่า env ไม่งั้นยังใช้ค่าเดิม)

> ห้ามเอา key ไปใส่ใน `index.html` เด็ดขาด ใครกด View Source ก็เห็นแล้วเอาไปใช้จนบิลขึ้นบ้านเรา
> key ต้องอยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ซึ่งก็คือ `api/ocr.js` ตัวนี้

## ตัวอ่านทำงานยังไง

1. ถ่ายรูป → เครื่องตรวจความคมชัดเองก่อน (Laplacian variance) ถ้าเบลอ มืด หรือสว่างจ้าเกินไป
   จะบอกให้ถ่ายใหม่ทันที **ไม่ส่งขึ้นเซิร์ฟเวอร์** จะได้ไม่เสียเงินฟรี
2. รูปที่ผ่านถูกส่งไป `/api/ocr` → Claude อ่าน **แถวรวมล่างสุด** ของตาราง
   (ไม่ต้องอ่านทีละ 31 บรรทัด แม่นกว่าและถูกกว่ามาก)
3. ได้ตัวเลข 6 คอลัมน์ + ค่าอาหาร/ค่าอาหารล่วงเวลา/ค่ากะ กลับมาเป็น JSON
   ยอดเงินรวมท้ายใบจะถูกหารกลับเป็นจำนวนวันให้อัตโนมัติ
4. หน้าตรวจทานจะขึ้น พร้อม % ความมั่นใจ **ช่องที่ระบบไม่มั่นใจจะขีดกรอบสีส้ม**
5. กดบันทึก → เงิน OT เข้าฟาร์ม

**ต้องกดยืนยันทุกครั้ง** ระบบจะไม่บันทึกเองโดยไม่ให้ตรวจ เพราะ OCR ไม่มีทางแม่น 100%
อ่านผิดคอลัมน์เดียวเงินก็ผิดทั้งเดือน

## สูตรคำนวณ OT

ถอดจาก `Cal_OT.xlsx` ตรวจแล้วว่าตรงกับ Excel ทุกช่อง

```
เรตต่อชั่วโมง = (ฐานเงินเดือน + ค่าครองชีพ + ค่าตำแหน่ง + ค่าเช่าบ้าน) ÷ 30 ÷ 8 × ตัวคูณ
```

| คอลัมน์ในใบ | ตัวคูณ |
|---|---|
| `1` วันหยุดประจำสัปดาห์ 8 ชม.แรก | ×1 |
| `1.5` OT วันธรรมดา | ×1.5 |
| `3` OT เกินเวลาในวันหยุด | ×3 |
| `1.5 Public` วันนักขัตฤกษ์ 8 ชม.แรก | ×1.5 |
| `2 Public` | ×2 |
| `3` นักขัตฤกษ์เกินเวลา | ×3 |

จุดที่ยังควรยืนยันกับ HR อยู่ 2 ข้อ — ดูคำเตือนในหน้าตั้งค่าของแอป

## กล้องไม่ขึ้น

- ต้องเปิดผ่าน **https** เท่านั้น (ลิงก์ Vercel ใช้ได้ เปิดไฟล์จากเครื่องตรง ๆ ไม่ได้)
- ครั้งแรกต้องกด **อนุญาต** ตอนเบราว์เซอร์ถาม
- เผลอกดปฏิเสธไปแล้ว → กดไอคอนซ้ายช่อง URL → เปิดสิทธิ์กล้อง → โหลดหน้าใหม่
- ยังไม่ได้จริง ๆ ใช้ปุ่ม **เลือกรูปจากเครื่อง** แทนได้ ผลลัพธ์เหมือนกัน

## ความเป็นส่วนตัว

เงินเดือน รายจ่าย และเป้าหมาย เก็บใน `localStorage` ของเครื่องเท่านั้น ไม่เคยถูกส่งออกไปไหน
มีแค่ **รูปใบ OT** ที่ถูกส่งไปให้ Claude อ่านตอนกดถ่าย และไม่ได้ถูกเก็บไว้บนเซิร์ฟเวอร์
